## 1. What Theorem B's proof really uses of (ST), and the generalisation

* The cubic bound E ≤ κ²λ³ (curvature) is **not used structurally anywhere**. It enters only through (i) chord–arc (CA)
  at the start, (ii) the start value of pairs that are near at t_s, (iii) N(t_s) in the first term of Step 3, where it
  must beat the amplification (min(g_s,32R)/g₂)^{22v}. This is the content of [B]'s unrefereed "relaxed start" remark;
  Theorem P7.B contains a complete proof of a statement of that type.
* All structural steps survive with invariant exponent 1 + 2γ, 0 < γ ≤ 1/4: tilt lemma (constant C_TL = 16.5/γ: a
  geometric series over scales — this is the only place where γ → 0 hurts, and the reason for v₀ ∝ γ²); far forcing
  ∫g^{ν+γ−2}dg (converges at ∞, concentrated at g ≈ λ); near terms I, II (unchanged in form); length ∫g^{2γ−1}dg
  (converges at 0 iff γ > 0).
* "Theorem B_θ": start exponent θ₀ = 1 + 2a′, invariant exponent θ₁ = 1 + 2γ. Needed: a′ ≥ γ + 22v (start beats the
  amplification), v ≤ 2·10⁻¹¹γ² (θ₁ − 1 against the near-pair constants 4.5·10⁹/γ²). So v₀ depends on θ₁ − 1 = 2γ and the
  admissible γ on θ₀ − θ₁. The normalisation is M = (γ/50)R^{−γ} (so that tilts at scale R are ≤ 0.33 and ϑ ≤ 2).
* **The end costs nothing new.** [B, Theorem B] was "restricted to legs whose target stays within the arc where (ST)
  held". Every estimate for a pair (a,b) only involves the arc from the base to b; if the arc where the start
  condition holds reaches the END E of the unseen set (construction cut at E), there are no other legs. The only new
  points: (α/β) the *last legs*: I sharpened (I1) to l ≤ (9/8)λ (the proof gives 1.00001λ) so that
  "U − u_{a_j} < ε/2 ⇒ remaining length ≤ ε ⇒ final leg" (Step 1(a)(β)) — with l ≤ 2λ this fails (one gets ≤ 2ε);
  and K̃ via the Claim of Theorem R with b* = b_E, K_T = 0.
  So the obstruction on the hooked arm was never the end as such but the start data: P6a's negative result on
  Theorem B′ is the case a′ ≈ v < γ + 22v.
* Wasteful constants: for a two-pass from Theorem B (γ₁ = 1/4, a′ = 1/4 − 7v, γ = 1/8): v ≤ 3·10⁻¹³, and
  R ≈ (γ/(400C₀))^{1/a′} with C₀ ≈ 2.9R₁^{−1/4} gives R ≈ 10⁻¹⁶R₁, hence v ≲ 10⁻²³R₁/(4U+2). Absolute, ε-independent.

## 2. Passive phases

**(a) far phase — Lemma P7.A (PROVED).** Exact form with Lemma 3(e): if dist(P, hull of the piece) ≥ ρ₀ ≥ 4·(length of
the piece)·e^{vT/ρ₀}: N(t) ≤ e^{1.375vT/ρ₀}[N(0) + 2.5vT l_t^{3/2}/ρ₀²], l_t ≤ e^{vT/ρ₀}l₀ (also with time-dependent ρ₀(t)). The
additive term is a curvature increment vT/ρ₀² (N-exponent 3/2): harmless for any class N ≤ Cλ^{1/2+γ}, γ ≤ 1.

**(b) tangential departure — Theorem P7.D (PROVED), and the lead's expectation REFUTED in its literal form.**
Method (new, simpler than a bootstrap): with the departure direction û *frozen*, D = ½w|T − û|² obeys a **pointwise**
law in the label (Fact 0.3), the transversal offset obeys the exact law y′ = v(f/ρ)y, and ρ_s ≥ 0.49(u_s + ε + τ). So each
front point's tilt against û is amplified by at most ((u_s+ε+τ)/(u_s+ε))^{4.1v}; near pairs are summed dyadically with
N² ≤ μ_û; far pairs use Lemma 3(e) with the alignment supplied by μ_û. No continuity argument over a family is needed.
Result: N(a,b;t_E+τ) ≤ 2.9ϑ₀(λ+τ)^{7v}λ^{1/2+γ−7v} for all pairs, λ ≤ l ≤ 1.03λ, uniformly in ε.
* What is true about the lead's question: for each *fixed* point the tilt against û is multiplied by a finite
  factor ≈ ((u_s+τ)/u_s)^{v/(1+v)} (radial stretching of transversal offsets, rate v/ρ), but this factor depends on the
  distance u_s from the end and is unbounded as u_s → 0. So the tilt profile
  ϑ(u) ∝ u^γ becomes ∝ u^{γ−v/(1+v)}τ^{v/(1+v)}: **same class, exponent lowered by v/(1+v), constant bounded** — not "same
  exponent". Proposition P7.D′ proves the lower bound (exact transversal law), so this is sharp. For bounded-curvature
  data (γ = 1) it is N7's a′ = 1/(1+v).
* Consequence for the design: a tangentially left end has a′ = γ_before − v/(1+v) (proved: ≥ γ_before − 7v) ≫ 22v: benign.

**(c) transversal departure — Proposition P7.C (PROVED for the model: straight arc, exact perpendicular start);
L-7 (F2) REFUTED beyond first order.** Exact solution: ρ sinθ tan^v(θ/2) = r, τ/r = [cotθ·t^{−v} + v(1 − t^{1−v})/(1−v)]/(1+v),
X = r t^{−v}ê + v(rJ − τ)n̂, tan Θ = D₂/D₁ (formulas in the claims file), μt^v(1 − 2t^{1−v})/(1+v) ≤ tanΘ ≤ μ(1+v)t^v/(1 − vμ),
Θ ≈ c_v(r/τ)^{v/(1+v)}. The rotation is ≈ v only for moderate r/τ; it decays to 0 at the end like (r/τ)^{v/(1+v)}
(= arclength^v): the differential rotation per e-fold of scale is ≈ v²(r/τ)^{v/(1+v)}, second order in v but with the
*marginal* exponent a′ = v < μ. **A transversally left end is a hook** (amplitude v instead of the wedge) — consistent
with N7's universality remark ("any end left at a non-zero angle has a′ = v"; for ω = π/2 "no overshoot" but the same
fixed point). It is NOT covered by Corollary P7.E. Designs must make the LAST-MET end a tangentially left one.

## 3. Two-pass (Corollary P7.T, PROVED) and what remains design-dependent

Chain: first pass (Theorem P7.B, exponent γ₁) stopped at a leg start t_E, E = a_j → Lemma P7.H: (D1) with
ϑ₀ = 0.96R₁^{−γ₁} → straight back by D (Theorem P7.D) → any path at distance ≥ ρ₀ from the piece Γ (Lemma P7.A) → at t₁:
N ≤ 2.9R₁^{−γ₁}λ^{1/2+γ₁−7v} + 2.8(vT/ρ₀²)λ^{3/2} on Γ, i.e. (E1) with a′ = γ₁ − 7v. Then Corollary P7.E for the second pass.
**Precise gaps left to the design (not holes in the proofs):**
 (G1) (E1), (E2) must be verified on ALL of the second-pass arc A, including pairs not contained in Γ and pairs
   straddling ∂Γ (needs an overlap of length ≥ R between Γ and the region controlled otherwise), and the separation
   (E2) (A does not come within c_sep of itself).
 (G2) Lemma P7.H's crude tilt constant forces U_Γ + D ≤ R₁·20^{−1/γ₁} (6·10⁻⁶R₁ for γ₁ = 1/4) for the *proved* part of the
   straight departure; afterwards Harry only has to stay ≥ ρ₀ ≥ 5U_Γ away (he may keep walking straight). If the
   design knows (D1) with a small ϑ₀ directly (e.g. from (ST) data), Theorem P7.D applies with (D2): ϑ₀(U_E+D)^γ ≤ 1/20.
 (G3) The second pass starts at the *other* end of A; that start (and every other end met on the way) is the design's
   problem. Theorem P7.B only needs the leg-start configuration P(t_s) = x_{a_s}(t_s) and (ST_γ).
 (G4) The departure must be exactly collinear with the last leg (û = direction of leg j), from a leg start.
 (G5) If the last-met end was left transversally or at a wedge, a′ = v: outside the theorem (N7's nonlinear regime).

## 5. Caveats / things a referee should look at first

1. Step 1(a)(β) of Theorem P7.B (the only genuinely new step for the end) and the use of (J1) with 9/8 throughout.
2. Step 4, re-derived constants (C_μ, C₁, C_ϑ, the three cases for |p(s)|) — transcribed from [B] with l ≤ (9/8)λ and
   exponent γ; arithmetic is by hand.
3. Theorem P7.D: the pointwise Gronwall (4.4), the dyadic sum (β) (uniformity in ε rests on 1/(2^q − 1) ≤ 1.001), and
   the length bound (iii) (uses 2γ ≥ 14v and (D2)).
4. Proposition P7.C is for the idealised model (exactly straight arc, exactly perpendicular, Harry starting ON the
   end); a perturbative version for real fronts is not proved (not needed for the negative conclusion's mechanism,
   but the statement "every transversally left end has a′ = v" is NUMERICAL/N7 + this exact model).
5. Nothing here handles a hooked last-met end (a′ ≤ γ + 22v): that remains N7's nonlinear regime.
